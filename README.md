# Sentiment Analysis on Reviews

## Overview
This project uses Machine Learning to analyze customer reviews and classify them as positive or negative.

## Features
- Text preprocessing
- Sentiment classification
- Review analysis
- Machine Learning based prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Project Structure
- Preprocessing.py : Cleans and prepares text data
- README.md : Project documentation

## How to Run
1. Clone the repository
2. Install required libraries
3. Run the Python files
